WPFW opdracht 1

Voor deze opdracht heb ik het fundament van mijn persoonlijke portfoliosite gemaakt. In deze blog laat ik stap voor stap zien hoe ik van het leren van de basis van HTML en CSS naar mijn uiteindelijke website ben gegaan.

HTML CSS Flexbox CSS Grid Responsive
01

Begin van de opdracht

Voor deze opdracht moest ik een statische en responsive portfoliosite maken. De website moest minimaal bestaan uit een Whoami-pagina, een projectenoverzicht en een blogoverzicht. Deze pagina's moesten met een werkende navigatie met elkaar verbonden zijn.

Aan het begin van de opdracht had ik nog weinig ervaring met HTML en CSS. Daarom ben ik eerst begonnen met het leren van de basis voordat ik de website verder ging uitwerken.

02

De basis van HTML en CSS leren

Mijn eerste stap was het leren en oefenen van de basis van HTML en CSS. Dit heb ik gedaan tijdens de lessen en door video's van Bro Code te bekijken.

Ik heb hierbij onder andere geleerd hoe een HTML-pagina is opgebouwd en hoe ik met CSS de vormgeving van een pagina kan aanpassen. Ook heb ik geleerd over onderwerpen zoals kleuren, het box model en verschillende manieren om elementen op een pagina te plaatsen.

Voor mijn kleuren ben ik HSL gaan gebruiken. Hiermee kan ik de hue, saturation en lightness van een kleur aanpassen. Ik ben vervolgens zelf gaan experimenteren met verschillende donkere kleuren en paarse accenten.

Tijdens het oefenen maakte ik eerst kleine onderdelen om te kijken hoe verschillende HTML-elementen en CSS-regels werkten. Daarna ben ik deze kennis gaan gebruiken voor mijn eigen portfolio.

03

Eerste versie van mijn website

Nadat ik de basis beter begreep, ben ik begonnen met de eerste versie van mijn website. Ik heb eerst de verschillende HTML-pagina's aangemaakt en een navigatie toegevoegd zodat ik tussen de pagina's kon wisselen.

In het begin gebruikte ik float om onderdelen van mijn navigatie naast elkaar te plaatsen. Dit werkte, maar ik merkte dat het lastiger werd om de elementen goed uit te lijnen.

Ook liep ik tegen problemen aan toen ik mijn blogpagina in een aparte map plaatste. Mijn CSS en links werkten toen niet meer zoals verwacht. Hierdoor heb ik geleerd hoe relatieve paden werken. Vanuit mijn blogs-map gebruik ik bijvoorbeeld ../ om één map terug te gaan.

04

Een ontwerp maken in Figma

Ik was eerst vooral direct bezig met het schrijven van HTML en CSS. Naar aanleiding van feedback ben ik meer gaan nadenken over het ontwerp voordat ik verder ging met programmeren. Daarom heb ik de layout van mijn website in Figma uitgewerkt.

Bij het ontwerp heb ik rekening gehouden met twee gebruikersscenario's. Het eerste scenario is een bezoeker die snel wil weten wie ik ben en wat ik doe. Daarom is mijn Whoami-pagina de startpagina en staat de belangrijkste informatie over mij daar direct zichtbaar.

Het tweede scenario is een bezoeker die wil zien wat ik tijdens mijn opleiding heb gemaakt. Via de navigatie kan deze bezoeker naar mijn projecten gaan. Daar kan de bezoeker lezen wat een project inhield, wat mijn bijdrage was en wat ik ervan heb geleerd.

Voor de vormgeving heb ik gekozen voor een donkere achtergrond met lichte tekst en paarse accenten. Ook heb ik ervoor gekozen om informatie in cards te plaatsen zodat verschillende onderdelen duidelijk van elkaar gescheiden zijn.

Dezelfde navigatie komt op iedere pagina terug. Hierdoor hoeft een bezoeker niet opnieuw uit te zoeken hoe hij naar een ander onderdeel van mijn portfolio kan gaan.

05

Het ontwerp uitwerken

Na het maken van het ontwerp ben ik de website verder gaan uitwerken met HTML en CSS. Voor de HTML heb ik semantische elementen gebruikt zoals nav, main, header, section en footer.

Tijdens het maken van de layout ben ik Flexbox gaan gebruiken. Hiermee kon ik bijvoorbeeld mijn navigatie en de introductie op mijn Whoami-pagina makkelijker uitlijnen.

Flexbox bleek voor mijn navigatie beter geschikt dan de float die ik eerst gebruikte. Met Flexbox kan ik elementen naast elkaar zetten en eigenschappen zoals align-items en gap gebruiken om de uitlijning en ruimte te bepalen.

Voor onderdelen waarbij ik meerdere kaarten in rijen en kolommen wil weergeven, heb ik CSS Grid gebruikt. Hiermee kan ik bijvoorbeeld aangeven dat een overzicht op een groter scherm uit meerdere gelijke kolommen bestaat.

Voor kleinere onderdelen zoals mijn skill-tags gebruik ik juist Flexbox met flex-wrap. De tags hoeven geen vaste indeling in rijen en kolommen te hebben en kunnen gewoon naar de volgende regel gaan als er te weinig ruimte is.

06

De website responsive maken

Toen de basis van de website stond, ben ik gaan kijken hoe de pagina's eruitzagen op verschillende schermgroottes. Hiervoor heb ik media queries toegevoegd aan mijn CSS.

Op een groot scherm kunnen meerdere kaarten naast elkaar staan. Op een kleiner scherm worden dit minder kolommen en op een telefoon kunnen de kaarten onder elkaar komen te staan.

Ook de introductie op mijn Whoami-pagina verandert op een kleiner scherm. Op een desktop staan de tekst en afbeelding naast elkaar, terwijl deze op een telefoon onder elkaar worden geplaatst.

Bij onderdelen zoals mijn skill-tags gebruik ik flex-wrap. Hierdoor kunnen de tags automatisch naar een nieuwe regel gaan wanneer er niet genoeg ruimte beschikbaar is.

07

Testen en verbeteren

Nadat de website grotendeels klaar was, heb ik de pagina's getest en gecontroleerd. Ik heb hierbij onder andere gekeken naar de werking van de navigatie, verschillende schermgroottes en de structuur van mijn HTML.

Met een HTML-validator heb ik mijn HTML gecontroleerd. Hierbij kwam ik er bijvoorbeeld achter dat ik na een h1 direct een h3 gebruikte. Ik heb dit aangepast naar een h2 zodat de headingstructuur logisch blijft.

Ook heb ik Lighthouse gebruikt om onder andere de toegankelijkheid van mijn website te controleren. Daarbij heb ik gekeken naar zaken zoals kleurcontrast, alt-teksten en de structuur van de pagina.

Verder heb ik mijn website op verschillende schermbreedtes bekeken om te controleren of er geen horizontale scroll ontstond en of de inhoud leesbaar bleef.

08

Request/response-cyclus

Tijdens deze opdracht heb ik ook geleerd wat er gebeurt wanneer iemand mijn website opent. De browser stuurt eerst een HTTP-request naar de webserver om een HTML-pagina op te vragen. De server stuurt deze pagina vervolgens terug met een HTTP-response.

Browser → HTTP Request → Webserver
Browser ← HTTP Response ← Webserver

Nadat de browser de HTML heeft ontvangen, ziet deze welke andere bestanden nodig zijn. Voor bijvoorbeeld style.css en afbeeldingen worden aparte requests verstuurd.

Wanneer deze bestanden zijn ontvangen, gebruikt de browser de HTML voor de structuur en de CSS voor de vormgeving om uiteindelijk de website weer te geven.

09

Wat heb ik geleerd?

Aan het begin van deze opdracht had ik nog weinig ervaring met HTML en CSS. Tijdens het maken van mijn portfolio heb ik vooral geleerd door eerst de basis te leren en deze daarna zelf toe te passen en uit te proberen.

Ik begrijp nu beter wanneer ik verschillende technieken kan gebruiken. Flexbox is handig wanneer ik elementen in één richting wil plaatsen en uitlijnen. CSS Grid gebruik ik wanneer ik een duidelijk raster met rijen en kolommen wil maken. Ook weet ik nu beter wanneer flex-wrap handig is.

Daarnaast heb ik meer geleerd over responsive design, media queries, HSL-kleuren, relatieve paden en semantische HTML. Door mijn website te testen heb ik ook gezien waarom een goede headingstructuur, alt-teksten en voldoende kleurcontrast belangrijk zijn.

Een belangrijk punt dat ik meeneem naar een volgende opdracht is dat ik eerder over het ontwerp wil nadenken. In het begin begon ik vrij snel met programmeren. Door later eerst mijn ontwerp in Figma uit te werken, had ik een duidelijker beeld van waar ik met mijn HTML en CSS naartoe wilde werken.
